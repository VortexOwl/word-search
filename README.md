# Word Search

Утилита для подбора русских слов (существительных) по заданным фильтрам на длину слова, присутствующие/отсутствующие буквы и их позиции в слове. Поддерживаются консольный режим и веб-интерфейс на базе FastAPI.

## Возможности

- Фильтрация слов по:
  - длине слова;
  - символам, которые **обязательно присутствуют**;
  - символам, которые **гарантированно отсутствуют**;
  - позициям, где определённые символы **обязаны** находиться;
  - позициям, где определённые символы **не могут** находиться.
- Формирование текстового отчёта и сохранение его в папку `docs`.
- Очистка от файлов директории для формирования отчётов.
- Web API (FastAPI) для настройки конфигурации и получения отчёта.

## Конфигурация и логика работы

1. **Конфигурация**

    Задаётся в `src/words/config.py` через классы `Config` и `LetterFilterModel`:

    `LetterFilterModel` — модель параметров фильтрации слов:

    * `word_length` — длина слова (по умолчанию 5);
    * `letters_included` — символы, которые **обязательно присутствуют**;
    * `letters_excluded` — символы, которые **гарантированно отсутствуют**;
    * `letters_fixed_pos` — позиции, где определённые символы **обязаны** находиться;
    * `letters_excluded_pos` — позиции, где определённые символы **не могут** находиться;
    * `is_save_file` — значение `True`/`False`, отвечающее на вопрос сохранять ли результат фильтрации в текстовый файл.

    `Config` — конфигурация приложения:

    Web:

    * `host` — хост (по умолчанию `127.0.0.1`);
    * `port` — порт (по умолчанию `8000`).

    Data:

    * `data_folder` — папка, где хранится словарь существительных слов русского языка (по умолчанию `data`);
    * `file_ru_words` — имя файла словаря существительных слов русского языка (по умолчанию `russian_nouns.txt`);
    * `encoding_ru_words` — кодировка для открытия файла словаря русского языка (по умолчанию `utf-8`);
    * `report_folder` — папка, куда сохраняется отчёт (по умолчанию `docs`);
    * `report_file` — имя файла отчёта (по умолчанию `Found words.txt`);
    * `path_data_folder` — вычисляемый путь к `data_folder`;
    * `path_file_ru_words` — вычисляемый путь к `file_ru_words`;
    * `path_report_folder` — вычисляемый путь к `report_folder`;
    * `path_report_file` — вычисляемый путь к `report_file`.

    Model:

    * `lfm` — экземпляр `LetterFilterModel` со значениями по умолчанию.

    В методе `__post_init__` программа приводит списки `letters_excluded_pos` и `letters_fixed_pos` к длине `word_length`, обрезая лишние и заполняя недостающие позиции пустыми строками.

2. **Логика работы**

    * вручную вводятся параметры фильтров или берутся из конфигурации по умолчанию;
    * из словаря русского языка отбираются слова, которые удовлетворяют фильтрам;
    * формируется текст отчёта с отобранными словами.

    Отчёт сохраняется в файл:

    ```text
    docs/<report_file>.txt
    ```

## Сценарии

### Сформировать и сохранить отчёт в текстовый файл

```bash
uv run start
```

При этом:

1. Параметры фильтров вручную вводятся с клавиатуры.
2. Из словаря русского языка отбираются слова, которые удовлетворяют фильтрам.
3. Отчёт сохраняется в папку `docs` под именем `<report_file>.txt`.

По умолчанию результат будет сохранён в файл:

`docs/Found words.txt`

### Сформировать и сохранить отчёт по фильтрам из конфигурации в текстовый файл

```bash
uv run basic
```

При этом:

1. Параметры фильтров берутся из конфигурации.
2. Из словаря русского языка отбираются слова, которые удовлетворяют фильтрам.
3. Отчёт сохраняется в папку `docs` под именем `<report_file>.txt`.

По умолчанию результат будет сохранён в файл:

`docs/Found words.txt`

### Очистить от файлов директорию для формирования отчётов

```bash
uv run clear
```

При этом:

1. Определяется путь к папке отчётов (по умолчанию `docs`).
2. Проводится безопасная очистка этой директории.
3. Формируется ответ об успешности данной процедуры, выводится в терминал и сохраняется в журнал.

По умолчанию очищается от файлов директория `docs/`.

### Web API

Приложение предоставляет web‑интерфейс на FastAPI для настройки фильтрации и получения отчёта.

Запуск через команду:

#### Запуск web‑сервера

```bash
uv run web
```

По умолчанию сервер стартует на `http://127.0.0.1:8000`

#### Документация API

После запуска перейдите в браузере:

* Swagger UI: `host:port/docs`

#### Основные эндпоинты

##### 1. Поиск и фильтрация слов

`GET /search-word`

Эндпоинт принимает данные и возвращает отчёт с отобранными по фильтрам словами.

Параметры запроса (query):

* `💾 Сохранить файл` (`saving file`), **опционально :**
  * `✔️ Да` — отчёт будет сохранён в файл и возвращён как файл;
  * `❌ Нет` — отчёт не сохраняется в файл, а возвращается как обычный текстовый ответ.
* `📙 Количество символов слова.` (`word length`) — длина слова (по умолчанию `5`);
* `✔️ Символы, которые гарантированно есть в слове.` (`included`) — символы, которые **обязательно присутствуют** (по умолчанию `аб`);
* `❌ Символы, которых гарантированно нет в слове.` (`excluded`) — символы, которые **гарантированно отсутствуют** (по умолчанию `лт`);
* `📗 Символы искомого слова, которые присутствуют в данных позициях.` (`fixed position`) — позиции, где определённые символы **обязаны** находиться (по умолчанию `["б", "", "", "", ""]`);
* `📕 Символы искомого слова, которые отсутствуют в данных позициях.` (`excluded position`) — позиции, где определённые символы **не могут** находиться (по умолчанию `["а", "", "", "", ""]`).

Поведение:

* Если `saving file` `=` `✔️ Да`, сервер:
  * сформирует отчёт;
  * сохранит его в папку, указанную в конфиге (`report_folder`, по умолчанию `docs`);
  * вернёт файл отчёта (`text/plain`) как `FileResponse`.
* Если `saving file` `=` `❌ Нет`, сервер вернёт отчёт в виде обычного текстового ответа (`PlainTextResponse`).

Пример ответа:

```text
Количество слов: 74

брасс буран басма бурак брика брань башка бубна бабьё букса буква богач баран
бакен будка байга басок базис банан барак бурка банка бурса бугай бейка будра
банда бурав багги божба базар бадан барон бирка бабка бареж бонза бочаг бювар
басня бекар бадья бахча браво басон бармы бакан баржа баска барыш башня бачок
бурда байка бакун бивак барич брада барин багаж багор бочка баснь бочар барий
байда бонна барка брага бомба букан бекас бюкса биржа
```

##### 2. Очистить от файлов директорию для формирования отчётов

`POST /clear-report-folder`

Эндпоинт безопасно очищает папку для отчётов от файлов.

Поведение:

* проверяет, что директория отчётов существует и является папкой;
* асинхронно удаляет все файлы в этой папке;
* возвращает сводку выполнения очистки в формате JSON.

Примеры ответа:

 - Успешный:
```json
{
  "success": 1,
  "errors": 0,
  "names of errors": []
}
```

 - С ошибками:
```json
{
  "success": 3,
  "errors": 1,
  "names of errors": [
    "Нет прав на удаление файла: docs/locked.txt"
  ]
}
```

## Установка и запуск

Проект инициализирован с помощью [uv](https://github.com/astral-sh/uv) и конфигурируется через `pyproject.toml`.

### Требования

- Python 3.14 (см. `.python-version`)
- Установленный `uv`

#### Примечание

Для установки зависимостей проекта через `uv` необходим доступ к PyPI. В некоторых регионах доступ к PyPI напрямую может быть ограничен.

### Загрузка

```bash
git clone https://github.com/VortexOwl/word-search.git
```

### Установка зависимостей

```bash
uv sync
```

### Запуск

```bash
uv run start
```

```bash
uv run basic
```

```bash
uv run clear
```

```bash
uv run web
```
